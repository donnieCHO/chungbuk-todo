1. To Do 등록

상세 관리 페이지에서 분리한 입력 영역입니다. 주요 과제와 Action Item을 1단 구성으로 차례대로 등록합니다.

관리 도구 전용 입력
Major Task

+ 주요 과제 설정

강의/장소/운영/사후처리 카테고리 아래에 업무 묶음을 만듭니다.

대표 기한은 참고용이며, 실제 화면 정렬은 Action due date를 우선합니다.
Action Item

+ Action Item 등록

주요 과제를 선택하고 실제 실행할 다음 행동, 담당, 회신 대기 대상, due date를 등록합니다.

한 개 담당자를 선택합니다.
응답이 필요한 기관을 복수 선택할 수 있습니다.
등록 후 내 Action과 상세 관리 화면에서 due date가 빠른 순서로 바로 정렬됩니다.
아래 두 리스트는 등록 폼 바로 아래에 배치한 운영 관리 영역입니다. 입력 후 Firebase 반영 결과를 즉시 확인할 수 있습니다.

4. 백업
