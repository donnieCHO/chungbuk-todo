📖 상세 관리 사용법

주요 과제를 만들고, 각 주요 과제 안에 실제 실행 단위인 Action Item을 추가·수정·완료 처리합니다.

Details Guide

1. 주요 과제 만들기

  • 주요 과제명, 카테고리, 책임자, 대표 기한을 입력합니다.
  • 주요 과제는 여러 Action Item을 담는 상위 묶음입니다.

2. Action Item 추가

  • 상단 Action Item 등록 폼에서 주요 과제를 고른 뒤 바로 세부 일을 추가합니다.
  • Action은 “실제로 완료할 다음 행동” 단위로 작성하고, due date는 필수로 입력합니다. 회신이 필요한 곳은 태그로 선택합니다.

3. 메모·링크 관리

  • 진행 상황은 Action Item의 메모에 남깁니다.
  • 자료는 Google Drive 등 외부에 올리고 링크만 첨부합니다.

4. 기존 데이터 변환

  • 평면 To Do 데이터가 있으면 상단에 변환 패널이 표시됩니다.
  • 변환 전 Firebase JSON 백업을 먼저 받아두는 것을 권장합니다.
운영 팁: 주요 과제는 업무 묶음으로 유지하고, 실제 체크할 일은 Action Item으로 쪼개세요. Action Item은 due date 기준으로 자동 정렬되어, 마감이 임박한 일부터 바로 보입니다.

⚠️ 기존 평면 To Do 데이터 변환

기존 `tasks/{key}` 평면 항목을 카테고리별 주요 과제로 묶고, 각 항목을 세부 Action Item으로 이동합니다. 링크와 메모도 Action Item으로 함께 옮깁니다.
