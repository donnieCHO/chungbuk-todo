📖 파일 링크 관리 사용법

Action Item에 첨부된 Google Drive, 네이버 MYBOX, OneDrive 등의 공유 링크를 한곳에서 찾습니다.

File Guide

1. 링크 찾기

  • 검색창에서 파일명, URL, 주요 과제명, Action Item으로 찾습니다.
  • 담당자 필터로 내가 관리하는 자료만 좁혀볼 수 있습니다.

2. 위치 구분

  • Action 링크가 기본 사용 구조입니다.
  • 기존 평면 링크와 주요 과제 링크도 호환 표시합니다.

3. 원본 파일 열기

  • 열기 버튼으로 외부 공유 링크를 새 탭에서 엽니다.
  • 상세 업무 이동 버튼으로 연결된 Action 위치를 확인합니다.

4. 링크 삭제 주의

  • 삭제는 Firebase DB의 링크 기록만 제거합니다.
  • Google Drive 등 외부 원본 파일은 삭제되지 않습니다.
파일 운영 원칙: Firebase에는 파일 자체를 저장하지 않습니다. 대용량 자료는 외부 파일 호스팅에 올리고, 이 페이지에서는 공유 URL만 관리합니다.

검색·필터

파일명, URL, 주요 과제, Action Item 기준으로 찾을 수 있습니다.
