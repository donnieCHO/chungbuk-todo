📖 내 Action 대시보드 사용법

이 화면은 전체 업무판이 아니라 “내가 지금 해야 할 세부 Action Item”을 빠르게 확인하는 메인 페이지입니다.

1. 내 담당자 선택

  • 내 보기에서 NSD, 네이버, 업스테이지, 세종대, 교육청 또는 전체를 선택합니다.
  • 담당자로 지정되었거나, 협업기관 또는 회신 대기 대상에 포함된 Action Item만 보입니다.

2. 2단계 구조 이해

  • 카테고리는 강의/장소/운영/사후처리입니다.
  • 카테고리 안에 주요 과제가 있고, 주요 과제 안에 실제 실행 단위인 Action Item이 들어갑니다.

3. 빠른 Action 추가

  • 주요 과제를 먼저 선택한 뒤 수행할 다음 행동을 입력합니다.
  • 주요 과제 자체를 새로 만들거나 구조를 다시 잡을 때는 상세 관리로 이동하세요.

4. 현황과 완료 확인

  • 전체 현황은 상단 대시보드에서 확인합니다.
  • 왼쪽 원형 체크를 누르면 완료가 됩니다. 완료된 Action Item은 기본적으로 접혀 있고, 우측 펼치기 버튼으로 볼 수 있습니다.
입력 원칙: “업무명”보다 “다음 행동”을 Action Item으로 적으면, 메인 화면에서 오늘 해야 할 일이 훨씬 선명하게 보입니다. 예: “숙박 후보 3곳 견적 비교표 만들기”.

⚠️ 기존 평면 To Do 데이터가 감지되었습니다
